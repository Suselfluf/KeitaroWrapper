# Keitaro Wrapper

Локальное веб-приложение для тестового задания Adrobot. Оно создаёт кампании с двумя потоками и редактирует состав и веса офферов существующей кампании.

[Исходное ТЗ и вложения](docs/assignment/README.md) · [TRACE.md — журнал реализации и проверок](TRACE.md) · [Архитектура](docs/ARCHITECTURE.md) · [Скринкаст (1:08)](docs/demo/keitaro-wrapper-screencast.mp4)

## Быстрый запуск

Понадобятся [uv](https://docs.astral.sh/uv/getting-started/installation/), Python 3.12 и доступ к [учебному Keitaro](https://keitaro-for-tests.etolegko.com/admin/). В чистой копии репозитория выполните из корня проекта:

```bash
uv sync --locked
cp .env.example .env
```

Заполните `.env` перед запуском:

| Переменная | Значение |
| --- | --- |
| `KEITARO_BASE_URL` | Корневой адрес учебного Keitaro, по умолчанию `https://keitaro-for-tests.etolegko.com`. Достаточно схемы и хоста. |
| `KEITARO_API_KEY` | Ключ из личного учебного доступа. Приложение передаёт его Keitaro с сервера. `.env` игнорируется Git. |
| `KEITARO_TEST_PREFIX` | Ваш префикс в формате `test_фамилия_`, например `test_example_`. Введите завершающее подчёркивание. |
| `KEITARO_DOMAIN_ID` | ID домена из каталога `GET /admin_api/v1/domains`. |
| `KEITARO_GROUP_ID` | ID группы кампаний из `GET /admin_api/v1/groups?type=campaigns`. |
| `KEITARO_TRAFFIC_SOURCE_ID` | ID источника трафика из `GET /admin_api/v1/traffic_sources`. |
| `DATABASE_URL` | Файл SQLite. Для первого запуска оставьте `sqlite:///./data/keitaro.db`. Для другого подключения или префикса задайте отдельный файл. |

Примените миграции и запустите веб-сервер:

```bash
uv run --locked --env-file .env alembic upgrade head
uv run --locked --env-file .env uvicorn app.main:app --host 127.0.0.1 --port 8765
```

Откройте [Кампании Keitaro](http://127.0.0.1:8765/). На странице доступны вкладки «Создать кампанию» и «Редактор офферов». Остановить сервер можно сочетанием Ctrl+C. Конфигурация предназначена для локального запуска одним процессом.

## Что проверить в интерфейсе

1. **Создание.** Введите название со своим префиксом и двухбуквенный код страны. В поле «ID оффера» найдите активный оффер по названию или ID, выберите его и нажмите «Создать кампанию». Интерфейс покажет ID кампании и номера двух потоков. Первый поток перенаправляет посетителей из выбранной страны на Google, второй направляет остальных в указанный оффер. Домен, группа и источник берутся из `.env`.
2. **Редактор.** В поле «ID кампании» найдите свою кампанию по названию или ID, выберите её и нажмите «Загрузить потоки». Найдите второй оффер по ID кнопкой «Найти оффер», добавьте его и проверьте веса в черновике. Можно закрепить вес, отменить черновик или нажать «Отправить в Keitaro». Удалённый из потока оффер остаётся в архиве и доступен для восстановления. При повторной загрузке редактор показывает веса из Keitaro, включая сумму меньше 100%.
3. **Отказы.** Несуществующий ID оффера вызывает ошибку при создании. При изменении состава или весов между загрузкой и отправкой редактор сообщает о конфликте и сохраняет черновик. После ответа подсказка об ожидании исчезает, а сообщение об успехе или отказе видно 5 секунд. Повторная загрузка предложит подтвердить сброс черновика.

Оба списка показывают до 20 совпадений, только ID и название. В предложениях редактора видны кампании со своим тестовым префиксом. Выберите строку мышью или стрелками и Enter. При недоступном поиске введите точный ID, закройте список клавишей Escape и отправьте форму её кнопкой или Enter.

Архив и закрепления сохраняются в SQLite. Черновик находится в памяти текущей вкладки. После обновления страницы загрузите потоки ещё раз.

## Проверки и история

Автоматический набор использует подставные HTTP-ответы и временные базы. Выданный ключ для него не нужен.

```bash
uv run --locked pytest -q
uv run --locked ruff check
```

Для каждого блока требований в [TRACE.md](TRACE.md#от-требования-до-проверки) указаны коммиты и способы проверки. Маршруты обёртки доступны в её [схеме OpenAPI](http://127.0.0.1:8765/docs) после запуска. Справочные маршруты и операции учебного Keitaro описаны в его [схеме OpenAPI](https://keitaro-for-tests.etolegko.com/openapi.json).

Текущее поведение описано в спецификациях [кампаний](docs/specs/campaign/spec.md), [редактора](docs/specs/editor/spec.md) и [материалов сдачи](docs/specs/delivery/spec.md). [Архитектурные решения](docs/decisions).
