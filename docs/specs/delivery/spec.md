# Спецификация области: Материалы сдачи

Area: DELIVERY · Updated: 2026-11-24
Coverage: partial

## Назначение

Инструкция по запуску и проверяемая история принятых решений.

## Требования

### DELIVERY-R1: Воспроизвести запуск и миграции

Implemented by: `rg -n -e "alembic upgrade head" -e "uvicorn app.main" README.md`
THE SYSTEM SHALL быть реализован на FastAPI и SQLAlchemy. Материалы сдачи SHALL включать публичный GitHub-репозиторий с README, в котором есть команды подготовки конфигурации, миграций и запуска.

#### Сценарий: Запуск из чистой копии

- WHEN проверяющий берёт чистую копию репозитория и выполняет команды из README с выданным ему доступом к тестовому Keitaro
- THEN миграции применяются, приложение запускается, оба сценария доступны через интерфейс

### DELIVERY-R2: Воспроизвести ход разработки и проверки

Implemented by: `rg -n -e "Журнал разработки" -e "Использование ИИ" docs/development-log.md`
Материалы сдачи SHALL содержать доступный из README журнал с хронологией ключевых действий, решениями и их основаниями, ссылками на изменения и результатами проверок. Журнал SHALL описывать участие ИИ и сохранять конфиденциальность внутренних материалов личного процесса разработки.

#### Сценарий: Проверяющий идёт от требования к проверке

- WHEN проверяющий открывает журнал из README и выбирает решение по маршрутизации или редактору
- THEN видит основание решения, соответствующее изменение в Git и способ повторить проверку
