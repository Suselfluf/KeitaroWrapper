# Спецификация области: Кампании

Area: CAMPAIGN · Updated: 2026-11-24
Coverage: partial

## Назначение

Создание кампании, настройка двух потоков и выбор начального оффера.

## Требования

### CAMPAIGN-R1: Создать кампанию по исходным данным

Implemented by: `rg -n create_campaign app/campaigns.py app/main.py`
WHEN пользователь передаёт название с префиксом `test_фамилия_`, код страны и существующий ID оффера, THE SYSTEM SHALL создать кампанию в тестовом Keitaro, задать ей выбранные при настройке приложения домен, группу и источник из справочников Keitaro и показать идентификатор созданной кампании.

#### Сценарий: Кампания видна в Keitaro

- WHEN пользователь передаёт допустимое имя, код страны и существующий оффер, а домен, группа и источник доступны
- THEN в Keitaro появляется кампания с переданным именем и тремя заданными параметрами, интерфейс показывает её ID

### CAMPAIGN-R2: Настроить два потока

Implemented by: `rg -n -e _verify_streams -e action_payload app/campaigns.py`
WHEN создаётся кампания, THE SYSTEM SHALL настроить ровно два потока в заданном порядке: первый перенаправляет трафик из указанной страны на Google, второй перенаправляет оставшийся трафик на выбранный оффер.

#### Сценарий: Проверка маршрутизации

- WHEN для кампании смотрят правила потоков в Keitaro
- THEN у первого потока установлен фильтр переданной страны и действие перенаправления на Google, у второго отсутствует ограничение этой страной и задан выбранный оффер

### CAMPAIGN-R3: Показать отказ при ошибке создания

Implemented by: `rg -n -e PARTIAL_CREATE -e CREATE_UNCONFIRMED -e NOT_FOUND app/campaigns.py`
IF входные данные отклонены или Keitaro не подтвердил настройку кампании и обоих потоков, THE SYSTEM SHALL показать причину отказа и не показывать успешное завершение.

#### Сценарий: Оффер не найден

- WHEN пользователь вводит ID, которого нет в Keitaro
- THEN интерфейс сообщает, что оффер не найден, кампания не создаётся

#### Сценарий: Один поток не настроен

- WHEN кампания создана, но Keitaro отклоняет настройку потока
- THEN интерфейс сообщает о неполном создании, видимый результат соответствует подтверждённым действиям

### CAMPAIGN-R4: Выбрать оффер при создании

Implemented by: `rg -n -e search_offers -e create-offer app/selection.py app/templates/index.html`
WHEN пользователь вводит текст в поле «ID оффера», THE SYSTEM SHALL предложить активные офферы, доступные настроенному ключу Keitaro, с фильтром по ID и названию. Пользователь может выбрать предложенный оффер или ввести точный ID. В список выводятся только ID и название оффера.

#### Сценарий: Найти и выбрать оффер

- WHEN пользователь вводит часть ID или названия активного оффера
- THEN видит совпадающие строки с ID и названием и может выбрать строку с клавиатуры. После выбора поле содержит ID.
