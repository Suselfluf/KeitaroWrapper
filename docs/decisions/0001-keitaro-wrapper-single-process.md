# ADR-0001: Интерфейс и прикладная логика в одном FastAPI-процессе

Date: 2026-11-24
Status: accepted
Decided by: владелец проекта
AI Guidance Level: Flexible

## Context

В тестовом два экрана и один Keitaro. Проверяющему нужен воспроизводимый запуск из чистого репозитория. Стек требований закрепляет FastAPI и SQLAlchemy, выбор фронтенда свободный.

## Decision

Отдавать страницы, статические файлы и JSON-операции обёртки из одного FastAPI-приложения. Использовать Jinja2 и браузерные модули JavaScript.

## Options considered

| Вариант | Что даёт | Цена | Решение |
| --- | --- | --- | --- |
| FastAPI с шаблонами и JavaScript | Единый запуск и общая точка входа для двух экранов | Меньше готовых компонентных абстракций | Принято |
| React с отдельной сборкой | Готовая экосистема компонентов | Второй набор зависимостей и отдельная сборка | Отклонено для объёма задания |

## Consequences

Один процесс обслуживает оба экрана. Браузер обращается к API обёртки по тому же адресу. Подключение к Keitaro выполняется сервером.

## Enforced by

| Файл или проверка | Что проверяет |
| --- | --- |
| `app/main.py`, `rg -n '^app = FastAPI' app/main.py` | Единая точка запуска. |
| `app/contracts.py`, `uv run --locked pytest -q tests/test_contracts.py` | Формы запросов и ответов в общем контракте. |

## Правила реализации

Сохранять единый запуск. Устройство шаблонов и JavaScript может меняться в рамках согласованных экранов и контрактов.
