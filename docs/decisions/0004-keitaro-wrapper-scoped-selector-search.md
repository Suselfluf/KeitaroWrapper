# ADR-0004: Серверный поиск с ограниченной выдачей для двух полей

Date: 2026-11-24
Status: accepted
Decided by: владелец проекта
AI Guidance Level: Strict

## Context

Ручная проверка показала, что для создания и открытия кампании нужно заранее знать ID. Учебный Keitaro предоставляет защищённые списки офферов и кампаний. У объектов есть дополнительные поля, которые интерфейсу выбора не нужны.

## Decision

Реализовать два маршрута чтения обёртки: `GET /api/offers?q=...` и `GET /api/campaigns?q=...`. Сервер возвращает не более 20 пар ID и названия. В выдаче офферов участвуют только активные, в выдаче кампаний — только записи с настроенным тестовым префиксом. Ищем по ID и названию. Поля поддерживают прямой ввод точного ID, в том числе при недоступности списка.

## Options considered

| Вариант | Преимущество | Цена | Решение |
| --- | --- | --- | --- |
| Фильтровать на сервере | Браузер получает короткий список совпадений | Поиск зависит от ответа сервера | Принято |
| Загрузить разрешённый каталог целиком | После загрузки можно фильтровать локально | В браузер попадают все записи сразу | Отклонено |

## Consequences

Два поля переиспользуют одно поведение выбора. Сервер Keitaro получает ключ от обёртки. В ответе обёртки есть только данные, нужные для выбора. Кампании фильтруются до отбора первых 20 совпадений. Прямой ID проверяется текущим сценарием создания или загрузки.

## Enforced by

| Файл или проверка | Что проверяет |
| --- | --- |
| `app/selection.py`, `rg -n -e startswith -e _RESULT_LIMIT app/selection.py` | Префикс до отбора результатов и ограниченная выдача. |
| `app/main.py`, `app/contracts.py` | Маршруты поиска, пара ID и названия и безопасные ошибки. |
| `app/static/selection.js`, `app/templates/index.html` | Два поля, управление с клавиатуры и прямой ввод. |
| `uv run --locked pytest -q tests/test_selection.py` | Поиск, пагинация, ограничение по префиксу и объёму, проекция и отказ. |

## Правила реализации

Соответствовать согласованному контракту и области видимости. Демонстрационные данные остаются в локальной проверке.
